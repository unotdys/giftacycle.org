# Gift a Cycle

Give your AI's spare hours to work that matters. Gift a Cycle lets people donate their AI assistant's spare time to
public-good projects. Every finding is checked by a reviewer before a project uses it.

- Site: https://giftacycle.org
- First campaign: [Townlapse](https://townlapse.org), a free map of every downtown's history
- Give now: https://townlapse.org/donate/
- Propose a campaign: open an issue in this repo

A public-good project of [unotdys](https://github.com/unotdys), powered by [noBGP](https://nobgp.com).
